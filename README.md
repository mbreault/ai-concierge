## How to iterate

1. Save new source material under `research/sources/` with its author, date and provenance in the source index. Preserve original wording and links; put corrections in a separate note.
2. Add ideas to the brainstorming backlog. Include the source, the question to test and the evidence that would change the offer.
3. Create a new file under `offerings/versions/` for each meaningful alternative. Use a date, author and version or descriptive stage; do not overwrite historical files. Label editorial extracts and proposals clearly.
4. Update the comparison and decision log. Distinguish a model recommendation, a working choice and Mike's approval; never infer approval from a synthesis.
5. Update `offerings/current.md` to point to the chosen snapshot, add a changelog entry, and review through a branch/PR. A new working favorite can remain marked **proposed** until approved.

Archived vendor prices and claims are historical research, not freshly verified market facts. Check the original vendor terms when preparing an actual quote.
