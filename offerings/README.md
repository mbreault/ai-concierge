## New versions

Create a new dated snapshot with: title, author/editor, date, source links, status, offer and scope, prices and units, support assumptions, and unresolved questions. Add a row here and in the comparison, record the reason in the decision log, then change the link in `current.md`. Never edit an old snapshot to make it agree with the new one.
